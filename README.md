# Portfolio · Carolina Soto

Portfolio de diseño de producto (UX/UI). HTML, CSS y JavaScript vanilla, sin dependencias ni build.

## Estructura

- `index.html`: estructura base
- `styles.css`: estilos y tokens de diseño (`:root`)
- `script.js`: router por hash, contenido de proyectos y casos de estudio, componentes
- `images/`: imágenes

## Ver en local

Abrir `index.html` en el navegador, o correr `python3 -m http.server` y entrar a http://localhost:8000.

## Publicar

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
